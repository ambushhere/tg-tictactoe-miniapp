# Крестики-нолики — Telegram Mini App

Игра открывается внутри Telegram по кнопке «Играть». Работает у всех ботов, без ограничений.

## Файлы
- `index.html` + `game.js` — сама игра (статическая страница, вся логика на телефоне).
- `bot.js` — бот: присылает кнопку «Играть» и ставит её в меню чата. Без зависимостей, Node.js 18+.

## Что умеет
- Три уровня сложности: «Легко», «Средне», «Сложно» (на «Сложно» бота не обыграть).
- Первым ходят по очереди: то ты, то бот.
- Счёт хранится в облаке Telegram (CloudStorage), то есть виден на всех устройствах пользователя.
- Цвета берутся из темы Telegram (светлая/тёмная), есть вибрация на ходах.

## Запуск
1. Страницу из этой папки (`index.html`, `game.js`) нужно выложить на любой **HTTPS**-хостинг
   (GitHub Pages, Netlify, Cloudflare Pages…). Telegram открывает Mini App только по https.
2. Запусти бота, указав токен и адрес страницы (PowerShell):
   ```powershell
   $env:BOT_TOKEN="123456:ABC..."; $env:WEBAPP_URL="https://твой-адрес/"; node bot.js
   ```
3. Напиши боту `/play` и нажми «Играть» (или кнопку «Играть» слева от поля ввода).

Бот нужен только чтобы выдать кнопку. После первого запуска кнопка меню остаётся,
и игра открывается даже если бот выключен.

## Проверить без Telegram
```powershell
py -m http.server 8766
```
и открыть http://localhost:8766 — игра работает и в обычном браузере (счёт в localStorage).
